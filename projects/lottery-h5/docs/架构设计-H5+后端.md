## 后端详细设计

### 2.1 技术栈

- **语言**: Python 3.11+
- **框架**: FastAPI（异步，高性能）
- **ORM**: SQLAlchemy (core) + asyncpg
- **数据库**: PostgreSQL（Supabase 托管）
- **缓存**: Redis（Supabase）
- **认证**: JWT + Passlib (bcrypt)
- **任务队列**: Celery + Redis
- **部署**: Docker + Railway / Vercel
- **监控**: Sentry（可选）

```python
@router.post("/register")
async def register(user_in: UserCreate):
    """
    邮箱注册
    - 检查邮箱是否已存在
    - 密码加密存储
    - 发送验证邮件（含激活链接）
    - 返回 success
    """
    user = await crud.get_by_email(user_in.email)
    if user:
        raise HTTPException(400, "邮箱已注册")
    user = await crud.create(user_in)
    # 发送验证邮件（异步）
    send_verification_email.delay(user.email, user.verification_token)
    return {"msg": "注册成功，请查收验证邮件"}

@router.post("/login")
async def login(form_data: OAuth2PasswordRequestForm = Depends()):
    """
    邮箱密码登录
    - 验证邮箱和密码
    - 检查是否已验证
    - 返回 JWT token
    """
    user = await crud.authenticate(form_data.username, form_data.password)
    if not user:
        raise HTTPException(401, "邮箱或密码错误")
    if not user.verified:
        raise HTTPException(403, "请先验证邮箱")
    token = create_access_token(user.id)
    return {"access_token": token, "token_type": "bearer"}

@router.post("/reset-password")
async def reset_password(email: EmailStr):
    """
    忘记密码
    - 发送重置链接（含 token）
    - 前端跳转重置页面
    """
    user = await crud.get_by_email(email)
    if user:
        send_reset_password_email.delay(email, user.reset_token)
    return {"msg": "重置链接已发送"}
```

```python
    1. 获取用户配置的模型
    2. 查询最近100期开奖数据

        draws=draws,
        lottery_type=req.lottery_type,
        count=req.count,
```

### 2.4 数据库 Schema（PostgreSQL）

```sql
-- 用户表
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    email VARCHAR(255) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    verified BOOLEAN DEFAULT FALSE,
    verification_token VARCHAR(64),
    reset_token VARCHAR(64),
    avatar_url TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 投注记录表
CREATE TABLE lottery_records (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    period VARCHAR(10) NOT NULL,
    type VARCHAR(20) NOT NULL,  -- 'double_color_ball' | 'super_lotto'
    red_balls INT[] NOT NULL,   -- PostgreSQL array
    blue_ball INT,
    front_balls INT[],          -- 大乐透前区
    back_balls INT[],           -- 大乐透后区
    draw_red_balls INT[],
    draw_blue_ball INT,
    draw_front_balls INT[],
    draw_back_balls INT[],
    matched_red_count INT DEFAULT 0,
    matched_blue BOOLEAN DEFAULT FALSE,
    matched_front_count INT DEFAULT 0,
    matched_back_count INT DEFAULT 0,
    prize_level VARCHAR(20),
    prize_amount DECIMAL(10,2) DEFAULT 0,
    bet_amount DECIMAL(10,2) DEFAULT 2.0,
    remarks TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX idx_records_user_created ON lottery_records(user_id, created_at DESC);
CREATE INDEX idx_records_period ON lottery_records(period);

-- 开奖结果表
CREATE TABLE draw_results (
    period VARCHAR(10) PRIMARY KEY,
    type VARCHAR(20) NOT NULL,
    draw_date DATE NOT NULL,
    red_balls INT[] NOT NULL,
    blue_ball INT NOT NULL,
    front_balls INT[],
    back_balls INT[]
);

CREATE INDEX idx_draws_date ON draw_results(draw_date DESC);

-- 预测配置表
CREATE TABLE prediction_configs (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    lottery_type VARCHAR(20) NOT NULL,
    provider VARCHAR(50) NOT NULL,
    api_url TEXT NOT NULL,
    model_id VARCHAR(100) NOT NULL,
    api_key_encrypted TEXT NOT NULL,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW(),
    UNIQUE(user_id, lottery_type)
);
```

## 安全考虑

1. **JWT Token**: 存储在 localStorage（XSS 风险）或 httpOnly cookie（CSRF）
2. **密码**: bcrypt 加密
3. **API Key**: 用户配置的加密存储（AES-256），后端转发时解密
4. **速率限制**: per IP 和 per user 双重限制（防止滥用）
5. **SQL 注入**: SQLAlchemy 参数化查询
6. **XSS**: Vue 自动转义，避免 `v-html`
7. **CORS**: 只允许前端域名访问

---

## 性能优化

- **Redis 缓存**：开奖数据、用户配置缓存（减少 DB 查询）
- **分页加载**：列表、历史记录
- **图片压缩**：OCR 前压缩到合适尺寸（< 1MB）
- **懒加载**：ECharts 图表按需加载
- **CDN**: 静态资源托管

# 彩票管理应用 - 需求规格文档（H5 + 后端版）

## 1. 项目概述

### 1.1 产品名称
**彩票智查** - 智能彩票管理与预测平台

### 1.2 产品定位
移动端 H5 应用 + 云端后端，提供拍照识别、开奖查询、中奖判断、历史记录、AI预测、数据统计等全功能服务。

### 1.3 核心价值
- ✅ 跨平台：手机浏览器直接使用，无需安装
- ✅ 智能识别：百度云 OCR，高准确率
- ✅ 实时开奖：联网查询最新开奖，自动判断中奖
- ✅ AI预测：支持多款大模型（用户自配Key）
- ✅ 数据云端：多设备同步，永不丢失
- ✅ 统计分析：年度ROI、中奖分布、趋势图表

## 2. 用户故事

### US-01: 注册登录
作为新用户，我想用邮箱注册账号并登录，以便云端同步我的投注记录。

### US-02: 拍照识别
作为彩民，我想拍照识别彩票号码，避免手动输入错误。

### US-03: 查询开奖
作为彩民，我想快速查询当期开奖结果，自动判断中奖等级和奖金。

### US-04: 历史管理
作为彩民，我想查看所有历史投注记录，支持筛选和搜索。

### US-05: 智能预测
作为彩民，我想使用AI模型获取下期号码推荐，并可配置我自己的大模型。

### US-06: 统计分析
作为彩民，我想查看年度购彩花费、中奖金额和ROI。

### US-07: 数据安全
作为用户，我希望我的数据存储在云端，多设备可访问。

## 3. 功能需求

### 3.1 用户认证模块

#### 3.1.1 注册
- 邮箱 + 密码（至少6位）
- 发送验证邮件（激活链接）
- 激活后才能使用完整功能

#### 3.1.2 登录
- 邮箱 + 密码
- "记住我"选项
- 忘记密码（重置链接到邮箱）

#### 3.1.3 退出
- 清除本地 token
- 返回登录页

---

### 3.2 彩票识别与查询（核心）

#### 3.2.1 拍照识别
1. 调用手机相机拍照
2. 调用 **百度智能云通用文字识别 API**（Base64 图片）
3. 解析文本，提取：
   - 期号（如 2024050）
   - 投注号码（双色球：6红+1蓝；大乐透：5前+2后）
4. 用户确认/修正识别结果
5. 保存为草稿并查询开奖

#### 3.2.2 开奖查询
1. 根据期号查询后端开奖 API
2. 后端从缓存或数据源获取开奖号码
3. 对比投注号码，计算中奖等级
4. 返回中奖结果（等级、奖金、匹配详情）

#### 3.2.3 手动录入
- 手动输入期号和号码
- 保存并查询开奖

---

### 3.3 记录管理

#### 3.3.1 列表
- 按时间倒序展示
- 分页加载（每页20条）
- 支持筛选：
  - 彩票类型（双色球/大乐透）
  - 中奖状态（全部/已中奖/未中奖）
  - 时间范围

#### 3.3.2 详情
- 投注号码 + 开奖号码（高亮匹配）
- 中奖等级、奖金
- 匹配详情（红球X中、蓝球Y中）
- 操作：编辑、删除

---

### 3.4 智能预测

#### 3.4.1 模型配置（设置页）
用户为每种彩票类型配置：
- 提供商：通义千问 / ChatGPT / DeepSeek / 本地 Ollama
- API 地址（可自定义）
- 模型 ID（如 qwen-max）
- API Key（加密存储）

#### 3.4.2 生成推荐
1. 选择彩票类型、推荐组数（1-10）
2. 调用后端 `/predict` 接口
3. 后端转发请求到用户配置的大模型 API（OpenAI 兼容格式）
4. 返回推荐号码 + 分析理由
5. 前端展示并支持保存到记录

---

### 3.5 统计分析

#### 3.5.1 年度概览
- 本年度购彩总花费
- 本年度中奖总金额
- ROI = (中奖 - 花费) / 花费 × 100%
- 投注次数、中奖次数

#### 3.5.2 中奖分布
- 各奖级次数和奖金柱状图

#### 3.5.3 趋势图表
- 月度花费 vs 中奖折线图
- 支持交互（点击查看月度详情）

---

### 3.6 设置

#### 3.6.1 个人信息
- 修改邮箱（需重新验证）
- 修改密码
- 头像上传（可选）

#### 3.6.2 通知设置
- 开奖提醒（推送）
- 中奖提醒（推送）
- 预测更新提醒

#### 3.6.3 数据管理
- 导出数据（JSON）

## 4. 非功能需求

### 4.1 性能
- 首屏加载 < 2s（4G）
- OCR识别响应 < 5s
- 预测生成 < 30s（取决于大模型）

### 4.2 兼容性
- 移动端 Safari (iOS 12+) / Chrome (Android 80+)
- 适配主流屏幕（360x640 ~ 414x896）

### 4.3 安全
- HTTPS 强制
- 密码加密存储（bcrypt）
- API Key 加密存储（AES）
- JWT token 认证
- 防暴力破解（登录失败限制）

### 4.4 可靠性
- 99% 可用性
- 数据备份（每日）
- 错误日志收集（Sentry）

## 7. 技术架构

### 7.1 前端（H5）
- **框架**：Vue.js 3 + Composition API
- **UI**：Vant 4（移动端组件库）
- **路由**：Vue Router
- **状态**：Pinia
- **HTTP**：Axios
- **图表**：ECharts
- **相机**：WebRTC `getUserMedia`
- **部署**：Vercel / 静态托管

### 7.2 后端
- **语言**：Python 3.11+
- **框架**：FastAPI（异步高性能）
- **ORM**：SQLAlchemy
- **数据库**：PostgreSQL（Supabase）
- **缓存**：Redis（Supabase）
- **认证**：JWT + Passlib（bcrypt）
- **任务队列**：Celery（异步OCR+预测）
- **部署**：Railway / Vercel Serverless / 自建

### 7.3 外部服务
- **百度智能云 OCR**：通用文字识别（高精度版）
- **开奖数据源**：自建爬虫（每日抓取彩票官网）
- **大模型 API**：用户自配置（通义千问、OpenAI等）

### 7.4 监控
- **Sentry**：错误追踪
- **Google Analytics**：用户行为分析

## 9. 关键决策点

1. **后端框架**：FastAPI 还是 Node.js Express？
2. **数据库托管**：Supabase（推荐）还是自建 PostgreSQL？
3. **开奖数据源**：哪个官网？抓取频率？
4. **OCR方案**：百度云免费额度够用吗？是否需要备用方案？
5. **大模型转发**：在后端转发还是前端直连？（建议后端转发保护用户Key）

## 11. 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 百度OCR限流 | 识别失败率高 | 实现多Key轮询 + 缓存识别结果 |
| 开奖数据源不稳定 | 查询失败 | 多源备份 + 本地缓存 |
| 大模型API费用高 | 用户不愿配置 | 提供免费额度 + 明确提示用户自担费用 |
| 用户量增长 | 服务器成本增加 | 使用Serverless，按量付费 |

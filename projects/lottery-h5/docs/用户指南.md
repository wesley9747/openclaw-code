# 双色球彩票管理 - 用户指南

## 📱 应用简介

这是一款专为双色球彩民设计的移动端 H5 应用，完全运行在浏览器中，无需安装 App，无需注册账号，数据安全存储在您的手机本地。

**核心特性**
- ✅ 离线使用（除 AI 预测需要网络）
- ✅ 无注册登录，隐私安全
- ✅ 简洁美观的移动端界面
- ✅ 拍照识别彩票号码
- ✅ 智能预测推荐（本地算法）
- ✅ 数据备份导出

---

## 📲 如何访问

### 方式一：直接打开文件
在手机浏览器中打开 `index.html` 文件即可使用。

### 方式二：本地服务器（推荐）
```bash
cd lottery-h5
npm install
npm start
```
然后访问：`http://localhost:3000`

### 方式三：部署到任何静态托管服务
将整个文件夹上传到：
- GitHub Pages
- Vercel
- Netlify
- 腾讯云 COS
- 阿里云 OSS

## 🎯 快速上手

### 1. 添加购彩记录

1. 点击首页的 **"添加记录"** 按钮
2. 输入期号（例如：`2024050`）
3. 选择 **6个红球**（1-33）
4. 选择 **1个蓝球**（1-16）
5. 可选填写备注
6. 点击 **"保存"**

### 2. 拍照识别（实验性功能）

1. 点击首页的 **"拍照识别"** 按钮
2. 授权相机访问权限
3. 对准彩票拍照
4. 系统自动识别号码（当前为模拟演示）
5. 确认号码无误后自动填充到添加表单

> ⚠️ 注意：当前版本 OCR 为模拟实现，真实场景需要集成 Tesseract.js 或调用后端 API。

### 3. 查看和编辑

- **查看统计**：首页顶部显示总记录数、中奖次数、总奖金
- **查看记录**：最近 10 条记录展示在首页
- **编辑**：点击记录下方的 **"编辑"** 按钮
- **删除**：点击记录下方的 **"删除"** 按钮

### 4. 智能预测

切换到 **"预测"** 标签页：

#### 冷热号统计
- 🔥 **热门红球**：最近30期出现频率最高的号码
- ❄️ **冷门红球**：最近30期出现频率最低的号码

#### 预测方式

**本地算法**（完全离线）
- 热门+冷门组合策略
- 奇偶平衡策略
- 邻号追踪策略
- 余数均匀分布策略
- 随机组合策略
- 提供 5 组不同方案供参考

**AI 智能推荐**（需网络）
- 调用 Qwen3-Max 进行分析（当前模拟）
- 提供推理过程和解释
- 置信度评分

## 📊 数据说明

### 数据格式

```json
{
  "id": 1712345678901,
  "period": "2024050",
  "redBalls": [3, 8, 15, 22, 27, 31],
  "blueBall": 9,
  "drawDate": null,
  "drawRedBalls": null,
  "drawBlueBall": null,
  "matchedRedCount": 0,
  "matchedBlue": false,
  "prizeLevel": null,
  "prizeAmount": 0,
  "remarks": "机选",
  "createdAt": "2025-06-20T03:30:00.000Z",
  "syncStatus": "pending"
}
```

### 存储容量
- 使用 LocalStorage，容量约 5MB
- 自动清理超过 1000 条的旧记录
- 支持数据导出备份（JSON 格式）

### 数据备份
在 **"设置"** 页面：
1. 点击 **"导出数据"** 按钮
2. 自动下载 JSON 文件到本地
3. 文件名格式：`lottery-records-YYYY-MM-DD.json`

## ⚙️ 设置与同步

### 飞书同步（可选）
1. 在 **"设置"** 页面的 "同步设置" 区域
2. 粘贴您的飞书多维表格链接
3. 点击 **"从飞书导入"**

> 该功能需要后端 API 支持，当前版本为离线单机版，同步功能暂不可用。

### 自动同步开关
- 关闭：完全离线模式
- 开启：在有网络时自动同步（需配置后端）

## ❓ 常见问题

### Q: 数据会丢失吗？
A: 数据存储在您手机的 LocalStorage 中，除非：
- 手动清除浏览器数据
- 卸载浏览器或应用
- 超过容量限制被自动清理
**建议定期导出备份！**

### Q: 可以多设备同步吗？
A: 当前版本不支持。如需同步，请使用飞书同步功能（需后端）或手动导出/导入。

### Q: AI预测需要花钱吗？
A: 调用 Qwen3-Max 需要 API 费用，由后端承担。用户端免费使用。

### Q: 拍照识别准确率如何？
A: 当前为模拟实现。真实 OCR 需要：
- 集成 Tesseract.js（完全本地，无网络）
- 或调用云端 OCR API（需要付费）

### Q: 中奖怎么判定？
A: 应用暂不支持自动开奖匹配。您需要：
1. 查看官方开奖结果
2. 手动编辑记录，填写开奖号码
3. 系统自动计算中奖情况

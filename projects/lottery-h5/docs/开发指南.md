# 开发指南

## 📦 环境搭建

### 必需工具
- **Node.js**: v18+ (推荐 v20 LTS)
- **Git**: 版本控制
- **代码编辑器**: VS Code (推荐)

### 可选工具
- **live-server**: 本地开发热重载
- **serve**: 静态文件服务
- **terser**: JavaScript 压缩
- **cssnano**: CSS 压缩

### 安装步骤

1. 克隆/下载项目
   ```bash
   cd lottery-h5
   ```

2. 安装依赖（可选，仅用于开发服务器）
   ```bash
   npm install
   ```

3. 启动开发服务器
   ```bash
   npm run dev
   # 或
   npx live-server --port=3000
   ```

4. 打开浏览器访问
   ```
   http://localhost:3000
   ```

## 🔨 核心模块说明

### constants.js - 常量中心

所有配置集中管理，修改一处即可影响全局：

```javascript
const CONSTANTS = {
    RED_BALL_MIN: 1,
    RED_BALL_MAX: 33,
    RED_BALL_COUNT: 6,
    // ...
    STORAGE_KEYS: { RECORDS: 'lottery_records' },
    APP_VERSION: '1.0.0'
};
```

---

### storage.js - 数据持久化

**功能**：
- 封装 LocalStorage 读写
- 自动数据迁移（版本升级时）
- 容量检查和自动清理
- CRUD 操作

**关键方法**：
```javascript
Storage.getRecords()      // .getAll()
Storage.addRecord(record) // .create()
Storage.updateRecord(id, updates)
Storage.deleteRecord(id)
Storage.getStats()        // 统计数据
```

**数据迁移示例**：
```javascript
migrateData(oldVersion) {
    if (oldVersion === '0.9.0') {
        // 升级逻辑：添加新字段
    }
}
```

---

### prediction.js - 预测算法

**5种策略**（全部本地运行，无网络）：
1. `hot-cold` - 热门 + 冷门
2. `parity` - 奇偶平衡
3. `neighbors` - 邻号追踪
4. `remainder` - 余数分布
5. `random` - 随机组合

**使用方法**：
```javascript
const result = Prediction.generate(historyDraws, 'hot-cold');
const analysis = Prediction.calculateStats(historyDraws);
```

**添加新策略**：
```javascript
const newStrategy = function(historyDraws) {
    // 实现逻辑
    return { redBalls, blueBall, reason };
};
// 注册到 strategies 对象
```

**核心职责**：

**渲染示例**：
```javascript
UI.renderRecordList(records, limit = 10)
UI.renderBalls([1,5,12,19,23,29], 14, { redClass: 'red' })
```

---

### camera.js - 相机与OCR

**功能**：
- 调用设备相机（后置优先）
- 拍照并获取图像数据
- OCR 识别（当前模拟）

**扩展真实 OCR**：
方案A：前端 Tesseract.js
```javascript
async realOCR(imageData) {
    const result = await Tesseract.recognize(imageData, 'chi_sim+eng');
    return this._parseOCRResult(result);
}
```

方案B：后端 API
```javascript
async realOCR(imageData) {
    const form = new FormData();
    form.append('image', dataURLtoBlob(imageData));
    const res = await fetch('/api/ocr', { method: 'POST', body: form });
    return res.json();
}
```

---

### app.js - 主控制器

**职责**：
- 应用初始化
- 事件绑定
- 页面路由
- 业务逻辑协调

**生命周期**：
```javascript
init() {
    this.bindEvents();
    this.renderHome();
}

bindEvents() {
    // 导航、弹窗、表单等事件
}

switchPage(name) {
    if (name === 'home') this.renderHome();
    if (name === 'prediction') this.loadPredictionPage();
}
```

**状态管理**：
- `selectedRedBalls`: Set<number>
- `selectedBlueBall`: number | null
- `editingId`: number | null

## 📦 构建优化

### 手动压缩（生产环境）

**JavaScript**：
```bash
npx terser js/*.js -o js/app.min.js --compress --mangle
```

**CSS**：
```bash
npx cssnano css/style.css css/style.min.css
```

**HTML 修改**：
```html
<script src="js/app.min.js"></script>
<link rel="stylesheet" href="css/style.min.css">
```

### 版本控制
每次发布前更新：
- `package.json`: `version`
- `index.html` 中的 meta 标签：`<meta name="version" content="1.0.0">`
- `docs/` 中的版本号

## 🐛 已知问题

1. **OCR 为模拟实现** - 真实场景需集成 Tesseract.js 或后端 API
2. **AI 预测需网络** - 当前纯离线可用，但 AI 按钮仅提示
3. **无开奖匹配** - 中奖判定需手动输入开奖号码
4. **无多设备同步** - 数据仅本地存储

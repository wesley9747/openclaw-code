# 彩票管理应用 - 需求规格文档（飞书应用 + 后端版）

## 1. 项目概述

### 1.1 产品名称
**彩票智查** - 飞书应用版本

### 1.2 产品定位
作为飞书工作台应用集成，使用飞书账号登录，提供拍照识别、开奖查询、中奖判断、智能预测、统计分析等功能。数据存储在云端，多端同步。

### 1.3 核心价值
- ✅ 飞书账号一键登录
- ✅ 工作台快速入口
- ✅ 飞书机器人推送（开奖/中奖提醒）
- ✅ 跨设备使用（手机、平板、电脑端飞书）
- ✅ 企业内部分享（可选）

## 3. 功能需求

### 3.1 飞书登录模块

1. **OAuth 2.0 授权流程**
   - 前端引导用户点击"登录"
   - 跳转到飞书授权页（应用已配置）
   - 用户确认授权 → 返回 `code`
   - 前端将 `code` 发送到后端 `/auth/feishu-login`
   - 后端用 `code` 换取 `access_token`，再获取用户信息
   - 后端创建/更新本地用户，返回 JWT
   - 前端存储 JWT，跳转首页

2. **用户信息同步**
   - 飞书字段：`user_id`、`email`、`name`、`avatar`
   - 本地用户表新增 `feishu_user_id` 字段用于关联

3. **退出登录**
   - 清除 JWT
   - 可选：飞书端清理登录态（调用 `logout`）

### 3.6 飞书机器人推送

**场景**：

## 5. 后端 API 设计（新增）

### 5.1 飞书登录

```http
POST /api/auth/feishu-login
Content-Type: application/json

{
  "code": "前端从飞书授权获取的临时code"
}

Response:
{
  "access_token": "jwt_token",
  "user": {
    "id": "uuid",
    "feishu_user_id": "ou_xxx",
    "email": "user@company.com",
    "name": "张三",
    "avatar": "https://..."
  }
}
```

**后端处理**：
1. 用 `code` 调用飞书 `oauth/access_token` 接口
2. 获取 `access_token`，再调用 `user/v1/user_info` 获取用户信息
3. 查询本地用户表，按 `feishu_user_id` 匹配
   - 存在 → 更新信息，生成 JWT
   - 不存在 → 创建新用户（建议邮箱验证后激活）
4. 返回 JWT 和用户信息

### 5.2 机器人推送（管理员或定时任务）

```http
POST /api/notifications/draw-result
Authorization: Bearer <admin_token>
{
  "user_id": "uuid",  // 或 feishu_user_id
  "period": "2024050",
  "prize_level": "四等奖",
  "prize_amount": 200
}
```

后端根据用户的 `feishu_user_id` 调用飞书机器人 webhook 发送卡片。

## 7. 技术架构

### 7.1 前端（飞书应用）
- **框架**：Vue 3 + Vant 4
- **集成**：飞书网页应用（不依赖飞书 JS SDK，仅用 OAuth 登录）
- **部署**：Vercel（公网可访问）
- **登录**：飞书 OAuth 2.0 授权码流程

### 7.2 后端
- 支持飞书登录接口
- 调用飞书 API 验证 code、获取用户信息
- 用户表增加 `feishu_user_id` 索引

### 7.3 飞书应用配置
- 应用类型：网页应用
- 首页地址：`https://your-app.vercel.app`
- OAuth 重定向地址：`https://your-app.vercel.app/auth/feishu/callback`
- 权限：`email`、`user_id`、`avatar`、`bot`（推送）
- 可见范围：指定企业或全员

## 9. 关键配置

### 9.1 飞书应用信息（需填充）

```env
# .env.local
FEISHU_APP_ID=cli_xxxxx
FEISHU_APP_SECRET=xxxxxxxx
FEISHU_OAUTH_REDIRECT_URI=https://your-app.vercel.app/auth/feishu/callback
FEISHU_BOT_WEBHOOK=https://open.feishu.cn/open-apis/bot/v2/hook/xxxxx
```

### 9.2 后端使用

```python
# services/feishu_service.py
import httpx

class FeishuService:
    async def get_access_token(self, code: str) -> str:
        url = "https://open.feishu.cn/open-apis/authen/v1/access_token"
        data = {
            "app_id": settings.FEISHU_APP_ID,
            "app_secret": settings.FEISHU_APP_SECRET,
            "grant_type": "authorization_code",
            "code": code
        }
        async with httpx.AsyncClient() as client:
            resp = await client.post(url, json=data)
            result = resp.json()
            return result["data"]["access_token"]

    async def get_user_info(self, access_token: str) -> dict:
        url = "https://open.feishu.cn/open-apis/authen/v1/user_info"
        headers = {"Authorization": f"Bearer {access_token}"}
        async with httpx.AsyncClient() as client:
            resp = await client.get(url, headers=headers)
            data = resp.json()["data"]
            return {
                "feishu_user_id": data["user_id"],
                "email": data["email"],
                "name": data["name"],
                "avatar": data["avatar"]["avatar_origin"]
            }
```

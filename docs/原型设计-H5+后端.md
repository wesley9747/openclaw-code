# 彩票管理应用 - 低保真原型设计（H5 + 后端版）

## 1. 用户流程（含登录态）

```
[首次访问]
   │
   ├─▶ 登录/注册页
   │       ├─ 邮箱登录 → 验证 → 首页
   │       ├─ 注册 → 验证邮件 → 激活 → 首页
   │       └─ 忘记密码 → 邮件重置 → 登录
   │
   └─▶ 已登录 → 首页
           │
           ├─ 拍照识别 → 相机 → OCR → 确认 → 后端查询 → 结果页 → 保存
           ├─ 手动添加 → 表单 → 保存 → 结果页
           ├─ 扫码识别 → 扫描二维码（如有）
           │
           ├─ 记录列表 → 筛选 → 详情
           │       └─ 编辑 / 删除
           │
           ├─ 智能预测 → 选择组数 → 调用AI → 展示 → 可选保存
           │
           ├─ 年度统计 → 图表展示 → 可导出
           │
           └─ 设置 → 模型配置 / 通知 / 备份 / 关于
```

## 4. 交互细节

### 4.1 拍照识别流程
```
用户点击"拍照识别"
   ↓
请求相机权限（首次）
   ↓
拒绝 → Dialog 提示去设置
   ↓
同意 → 显示相机预览
   ↓
用户对准 → 点击拍照
   ↓
显示 loading "识别中..."
   ↓
图片上传到后端 → 百度OCR
   ↓
返回识别结果 → 显示确认卡片
   ↓
用户可手动修正
   ↓
点击"确认"
   ↓
后端查询开奖 + 计算中奖
   ↓
显示结果页（中奖信息）
   ↓
自动保存到数据库
   ↓
提示"保存成功"，返回首页
```

### 4.2 下拉刷新
- 首页、记录列表支持 SwipeRefresh
- 触发后重新请求数据
- 显示"更新于 14:30"

### 4.3 空状态
- 无记录：插图 + "还没有投注记录" + "去拍照识别"按钮
- 网络错误：离线提示 + 重试按钮
- OCR识别失败：提示"识别失败" + 重试

### 4.4 加载状态
- 拍照识别：全屏 loading + 提示文案
- 预测生成：底部 progress bar + "AI正在思考..."
- 列表分页：底部 spinner + "加载中..."

## 6. 设计规范

### 6.1 色彩
- 主色：#1989FA（Vant 蓝）
- 红球：#FF6B6B
- 蓝球：#1989FA
- 成功：#07C160
- 警告：#FF976A
- 错误：#EE0A24
- 背景：#F7F8FA
- 卡片：#FFFFFF

### 6.2 间距
- 页面边距：16px
- 卡片间距：12px
- 元素间距：8px/12px/16px
- 按钮高度：44px（最小点击）

### 6.3 字体
- 标题：16px/18px，bold
- 正文：14px，normal
- 辅助：12px，light

# 彩票管理 H5 应用 - 低保真原型设计

## 1. 用户流程概览

```
未登录状态
    │
    ├─▶ 登录/注册页
    │       ├─ 邮箱登录
    │       └─ 注册新账号
    │
    └─▶ 登录成功 → 首页
            │
            ├─ 拍照识别 → 确认号码 → 保存记录
            ├─ 手动添加 → 填写表单 → 保存
            ├─ 查看历史 → 记录列表 → 详情
            ├─ 预测号码 → 选择模型 → 生成推荐
            └─ 统计ROI → 年度数据 → 图表
```

## 4. 关键交互说明

### 4.1 拍照识别
1. 点击"拍照" → `navigator.mediaDevices.getUserMedia()`
2. 权限拒绝 → 弹窗提示，引导去设置开启
3. 拍照成功后 → 显示识别结果预览
4. 用户可手动修正期号和号码
5. 确认保存 → 调用 API 保存 + 查询开奖
6. 结果页显示中奖情况

### 4.2 下拉刷新
- 首页、记录列表支持下拉刷新
- 触发图标旋转动画
- 刷新期间禁用重复触发
- 刷新完成显示"更新于 14:30"

### 4.3 空状态
- 无记录时显示插画 + 文案 + 引导按钮
- 无网络时显示离线提示，保留已缓存数据

### 4.4 加载状态
- 图片识别中：全屏 loading + 提示文案
- 预测生成中：进度条 + 预估时间
- 列表分页：底部 spinner + "加载中..."

### 4.5 错误处理
- OCR识别失败：提示"识别失败，请重试"，保留原图可重试
- 网络错误：toast 提示 + 重试按钮
- API调用失败：具体错误信息 + 建议操作

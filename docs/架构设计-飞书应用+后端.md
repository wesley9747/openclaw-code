### 2.3 核心接口

#### 2.3.1 飞书登录

```python
# api/v1/auth.py

@router.post("/feishu-login")
async def feishu_login(req: FeishuLoginRequest):
    """
    1. 用 code 换取飞书 access_token
    2. 获取用户信息（user_id, email, name）
    3. 创建或更新本地用户
    4. 返回 JWT
    """
    # 步骤1: 获取飞书 access_token
    feishu_token = await feishu_service.get_access_token(req.code)

    # 步骤2: 获取用户信息
    user_info = await feishu_service.get_user_info(feishu_token)

    # 步骤3: 查找或创建本地用户
    user = await crud.get_by_feishu_id(user_info["feishu_user_id"])
    if not user:
        user = await crud.create_from_feishu(user_info)
    else:
        user = await crud.update_from_feishu(user.id, user_info)

    # 步骤4: 生成 JWT
    jwt_token = create_access_token(user.id)

    return {
        "access_token": jwt_token,
        "user": {
            "id": user.id,
            "name": user.name,
            "email": user.email,
            "avatar": user.avatar_url
        }
    }
```

### 3.3 飞书登录 Store

```javascript
// stores/auth.js
import { defineStore } from 'pinia'
import { ref } from 'vue'
import api from '@/api/auth'

export const useAuthStore = defineStore('auth', () => {
  const token = ref(localStorage.getItem('token'))
  const user = ref(JSON.parse(localStorage.getItem('user')))

  const setToken = (newToken) => {
    token.value = newToken
    localStorage.setItem('token', newToken)
  }
  const setUser = (newUser) => {
    user.value = newUser
    localStorage.setItem('user', JSON.stringify(newUser))
  }
  const logout = () => {
    token.value = null
    user.value = null
    localStorage.removeItem('token')
    localStorage.removeItem('user')
  }

  const feishuLogin = async (code) => {
    const res = await api.feishuLogin(code)
    setToken(res.access_token)
    setUser(res.user)
    return res
  }

  return { token, user, setToken, setUser, logout, feishuLogin }
})
```

### 3.4 API 封装（Axios）

```javascript
// api/auth.js
import axios from '@/utils/axios'

export default {
  async feishuLogin(code) {
    return axios.post('/api/auth/feishu-login', { code })
  },
  async logout() {
    return axios.post('/api/auth/logout')
  }
}

// utils/axios.js
import axios from 'axios'
import { useAuthStore } from '@/stores/auth'

const instance = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL,
  timeout: 30000
})

instance.interceptors.request.use(config => {
  const authStore = useAuthStore()
  if (authStore.token) {
    config.headers.Authorization = `Bearer ${authStore.token}`
  }
  return config
})

instance.interceptors.response.use(
  res => res.data,
  async err => {
    if (err.response?.status === 401) {
      // 跳转登录
    }
    return Promise.reject(err)
  }
)

export default instance
```

### 3.5 飞书 OAuth 回调路由

```javascript
// router.js
import { createRouter, createWebHistory } from 'vue-router'
import Login from '@/views/Login.vue'
import Home from '@/views/Home.vue'
// ...

const routes = [
  { path: '/', redirect: '/home' },
  { path: '/login', component: Login },
  // 飞书 OAuth 回调
  {
    path: '/auth/feishu/callback',
    name: 'FeishuCallback',
    component: {
      template: '<div>登录中...</div>',
      async created() {
        const code = new URLSearchParams(window.location.search).get('code')
        const state = new URLSearchParams(window.location.search).get('state')
        // 验证 state 防 CSRF
        if (state !== localStorage.getItem('oauth_state')) {
          alert('授权失败')
          return this.$router.push('/login')
        }
        try {
          const authStore = useAuthStore()
          await authStore.feishuLogin(code)
          this.$router.push('/home')
        } catch (e) {
          alert('登录失败')
          this.$router.push('/login')
        }
      }
    }
  },
  { path: '/home', component: Home },
  { path: '/camera', component: Camera },
  // ...
]

export default createRouter({ history: createWebHistory(), routes })
```

## 部署配置

### 4.1 飞书应用配置

1. **创建应用**
   - 登录 [飞书开发者平台](https://open.feishu.cn/)
   - 创建「自建应用」→「网页应用」
   - 填写：
     - 应用名称：彩票智查
     - 首页地址：`https://your-app.vercel.app`
     -  Permissions → OAuth：`email`、`user_id`、`avatar`
     - 机器人权限：可选（用于推送）

2. **配置 OAuth**
   - 授权回调地址：`https://your-app.vercel.app/auth/feishu/callback`
   - 登录模式：`OAuth 2.0`

3. **发布应用**
   - 应用发布 → 工作台（指定可见范围）
   - 用户即可在工作台看到应用图标

## 安全考虑

1. **CSRF**: OAuth state 校验
2. **JWT**: 短期有效（7天），可刷新
3. **XSS**: Vue 自动转义，避免 `v-html`
4. **SQL 注入**: SQLAlchemy 参数化
5. **飞书 API 调用**：验证 `access_token`

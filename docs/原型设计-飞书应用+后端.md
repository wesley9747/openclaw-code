# 彩票管理应用 - 低保真原型设计（飞书应用版）

## 1. 用户流程

```
[从飞书工作台打开应用]
   │
   ├─ 检测登录态
   │     ├─ 未登录 → 飞书授权页 → 授权 → 返回应用
   │     └─ 已登录 → 首页
   │
   └─▶ 首页
           │
           ├─ 拍照识别 → OCR → 查询开奖 → 保存
           ├─ 手动添加 → 表单 → 保存
           │
           ├─ 记录列表 → 筛选 → 详情
           │       └─ 编辑/删除
           │
           ├─ 智能预测 → 生成 → 保存/分享
           │
           ├─ 年度统计 → 图表 → 导出
           │
           └─ 设置 → 模型配置 / 通知 / 关于

[后台定时]
   ├─ 每日开奖后 → 查询中奖用户 → 飞书机器人推送
   └─ 数据同步 → 更新开奖数据库
```

## 4. 交互细节（新增）

### 4.1 飞书登录流程
1. 首次打开，检测 `localStorage` 有无 JWT
2. 无 → 显示登录页，展示"使用飞书登录"大按钮
3. 点击 → `window.location.href = FEISHU_OAUTH_URL`
4. 飞书授权页 → 用户确认 → 跳转回 `callback?code=xxx`
5. 前端解析 `code`，POST 到后端 `/auth/feishu-login`
6. 成功 → 存储 JWT → 跳首页
7. 失败 → 提示并重试

### 4.2 开奖提醒推送
- 用户必须在设置页开启"开奖提醒"
- 后端定时任务（Celery）在开奖后查询用户中奖情况
- 若中奖且用户开启推送 → 调用飞书机器人Webhook发送卡片消息
- 消息内容：期号、奖金、详情链接

## 5. 飞书 JSAPI 使用（可选）

| 能力 | API | 用途 |
|------|-----|------|
| 获取用户信息 | `tt.getAuthCode` / 后端回调 | 登录 |
| 扫码 | `scancode` | 扫码识别彩票（可选）|
| 图片选择 | `chooseImage` | 从手机相册选择 |
| 分享 | `share` | 分享预测结果到会话 |
| Toast | `showToast` | 提示消息 |

**注意**：使用 JSAPI 需要将应用配置为 "小程序" 或 "网页应用+JSAPI权限"。
